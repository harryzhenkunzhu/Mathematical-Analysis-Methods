# 证明详解：按老师课件路线重写（纯文字与公式版）

[直接阅读合并 PDF](../pdf/gpt-All-Proofs.pdf)

按原课件分类为 000-Proof（000-ZSM）、102-Proof 至 110-Proof。000-PPT 与 101 没有实际证明，目录只说明未收录原因。所有内容在一份 PDF 中，使用分级书签及目录定位。

## 选取规则

判断依据是 `sources/` 中用户上传的老师原始课件，不是先前 gpt 讲义中补写的证明。只展示定理、写着 “One can prove”、仅要求 “Questions. Prove” 或只给证明提示，不自动收录。实际展示的代数推导、跨页续证和带推理的例证也纳入；不限于带有 Proof 标题的页面。同一结论的不同证明及跨课件重复出现的证明保留各自出处。

共整理 232 个来源条目，涉及 293 个原课件页面；一个条目可能含多个小证明，不能把条目数当作互不重复定理数。每项独立写出命题与条件、证明思路、详细推导及必要批注。全部由文字与 LaTeX 数学公式组成，不嵌入课件截图或原页 PDF。原始页码仅用于来源定位；正文可独立阅读。补充步骤与纠错明确标注。

每项标明原课件文件名、原 PDF 页码，以及已有 gpt 讲义的对应页脚编号。原课件页码从封面计 1；它与 gpt 讲义页脚编号不是同一套编号。

## 特别核查

- 102 的对称差结合、消去、交分配、集合族并的差异估计逐步展开。
- 103 的逆对应单值/单射证明补正；原页第三句须核对半单值定义，附反例说明不能照抄。
- 107 的有限交性质证明极值与序列证明分别保留；和、积的水平集证明沿老师路线解释存在参数的选取。
- 108 的闭图加紧容器定理保留有限覆盖路线；伪定理及错误逆像等式明确标作辨错条目。
- 109 保留归一化、抽子列、线性映射及凸组合的路线，并说明闭性、有限维和缩放有界性在哪里用到。
- 110 只整理原课件第 5 页同胚共轭推导和第 6 页一维介值证明；高维 Brouwer 与 Kakutani 的完整证明不纳入，因为课件没有展示。低维紧凸集未必与同维球同胚的问题单独批注，不把缺少前提的论证称为完整一般证明。

## 源码与重编译

在仓库根目录运行：

```bash
python3 scripts/build_proofs.py
```

需要 XeLaTeX 与 Noto CJK 字体，环境要求与仓库主 README 相同。静态入口为 `proofs/all-proofs.tex`，它只依赖 `tex/preamble.tex`，直接编译不需要原课件 PDF。`proof-index.json` 保存逐项来源页码，`enhancements.json` 保存额外展开内容，`statements.json` 保存逐条重新编写的命题及证明思路。

如需从已有逐页 notes 和人工选取范围重新生成入口，可运行 `python3 scripts/assemble_proofs.py`（额外需要 PyMuPDF）。然后再编译。直接编译已经整理好的静态入口不需要 PyMuPDF。

原课件的错误或伪证明以文字说明其错误步骤，并给出必要修正或反例。应复习成立的论证，不能把错误公式当作考试答案。此汇编不把自动编译或覆盖检查等同于对数学正确性的形式化验证。
