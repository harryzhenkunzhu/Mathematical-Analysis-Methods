## 选取规则

判断依据是 `sources/` 中用户上传的老师原始课件，不是先前 gpt 讲义中补写的证明。只展示定理、写着 “One can prove”、仅要求 “Questions. Prove” 或只给证明提示，不自动收录。实际展示的代数推导、跨页续证和带推理的例证也纳入；不限于带有 Proof 标题的页面。同一结论的不同证明及跨课件重复出现的证明保留各自出处。

共整理 231 个来源条目，涉及 294 个原课件页面；一个条目可能含多个小证明，不能把条目数当作互不重复定理数。每项独立写出命题与条件、证明思路、详细推导及必要批注。全部由文字与 LaTeX 数学公式组成，不嵌入课件截图或原页 PDF。原始页码仅用于来源定位；正文可独立阅读。补充步骤与纠错明确标注。

每项标明原课件文件名、原 PDF 页码，以及已有 gpt 讲义的对应页脚编号。`proof-index.json` 还列出本次汇编的实际 PDF 页码范围，便于直接跳转。原课件页码从封面计 1；它与 gpt 讲义页脚编号不是同一套编号。

## 源码与重编译

在仓库根目录运行：

```bash
python3 scripts/build_proofs.py
```

需要 XeLaTeX 与 Noto CJK 字体，环境要求与仓库主 README 相同。静态入口为 `proofs/all-proofs.tex`，它只依赖 `tex/preamble.tex` 与 `proofs/read-first.tex`，直接编译不需要原课件 PDF。`proof-index.json` 保存逐项来源页码；`proofs/detailed/*.py` 保存按数学主题编写的全部证明正文，`enhancements.json` 保存额外展开内容，`statements.json` 保存逐条重新编写的命题及证明思路。

如需从已有逐页 notes 和人工选取范围重新生成入口，可运行 `python3 scripts/assemble_proofs.py`（额外需要 PyMuPDF；每个条目缺少详细正文时生成器会立即报错）。然后再编译。直接编译已经整理好的静态入口不需要 PyMuPDF。

原课件的错误或伪证明以文字说明其错误步骤，并给出必要修正或反例。应复习成立的论证，不能把错误公式当作考试答案。此汇编不把自动编译或覆盖检查等同于对数学正确性的形式化验证。
